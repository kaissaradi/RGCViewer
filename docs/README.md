# Project Documentation

This folder contains the project documentation and specifications for RGCViewer.

- `docs/README.md` - entrypoint for docs.
- `docs/DEVELOPMENT_GUIDE.md` - development workflow, testing guide, and roadmap.
- `docs/specs/` - feature specification files.
- `docs/unused_code_report.md` - automated scan for candidate unused Python modules and doc locations.

> The repository root keeps `README.md` as the GitHub landing page.
